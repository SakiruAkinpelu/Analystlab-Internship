# Week 3 — SQL & Data Querying

## Overview
This project covers SQL querying and data analysis using two real-world datasets as part of the AnalystLab Africa Data Analytics Internship Program.

## Datasets
| Dataset | Source | Tool |
|---|---|---|
| Chinook Music Store | GitHub (lerocha/chinook-database) | PostgreSQL + pgAdmin |
| Sample Sales Data | Kaggle (kyanyoga/sample-sales-data) | MySQL + MySQL Workbench |

## Skills Demonstrated
- Core SQL: SELECT, WHERE, ORDER BY, GROUP BY, HAVING
- Aggregate Functions: SUM, AVG, COUNT, MIN, MAX
- Joins: INNER JOIN, LEFT JOIN, Multi-table JOINs
- Subqueries
- Window Functions: RANK(), ROW_NUMBER(), PARTITION BY, Running Totals

## Files
| File | Description |
|---|---|
| `Sakiru_Akinpelu_Week3_SQL_Script.sql` | All SQL queries for both datasets |
| `Sakiru_Akinpelu_Week3_Insights_Report.docx` | Business insights and analysis report |

## Key Findings
- USA was the #1 revenue country in both datasets
- Classic Cars generated over $3.9M — the top product line by far
- 1,519 tracks in the Chinook database have never been purchased
- Q4 consistently outperforms all other quarters across every year

## Tools Used
- PostgreSQL 16 + pgAdmin 4
- MySQL 8 + MySQL Workbench

## 📌 Project Overview

Built an interactive COVID-19 Global Dashboard analyzing over **676 million confirmed cases** across **201 countries** from January 2020 to March 2023 using the Johns Hopkins CSSE dataset.

---

## 📁 Dataset

**Source:** Johns Hopkins University CSSE  
**Files Used:**
- `time_series_covid19_confirmed_global.csv`
- `time_series_covid19_deaths_global.csv`
- `time_series_covid19_recovered_global.csv`

## 📈 Visualizations Built

- **Line Chart** — Global Case Trajectory
- **Bar Chart** — Monthly New Cases (2021–2023)
- **Bar Chart** — Case Fatality Rate by Continent
- **Donut Chart** — Case Distribution by Continent
- **Interactive Buttons** — Year filters using Power BI Bookmarks

---

## 💡 Key Insights

1. Omicron surge — January 2022 recorded 90.5M new cases, 3× any previous monthly peak
2. US accounted for 15.3% of all global cases
3. Africa's 2.34% fatality rate was highest globally despite lowest reported cases
4. South Korea and Japan achieved fatality rates as low as 0.11%
5. Cases dropped 98.7% from peak by March 2023
